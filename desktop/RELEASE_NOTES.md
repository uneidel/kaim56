# kAIm56 for Mac — release notes

## 0.1.1

- The agent picker no longer shows the members of a squad — you talk to a squad through its chat, not to each member. Needs a manager from 2026-11-12 on; an older one shows them as before.

## 0.1.0

- First version: chat with your agents — the same chats as on the phone and in the web UI, replies stream in, Stop ends one.
- **Waiting for you**: approve, deny, answer questions and reviews of your agents and squads.
- The manager's notifications appear as macOS notifications; the list is in the app.
- Connects only over iroh (end-to-end encrypted, no public URL): Settings shows this Mac's NodeId — add it to the manager's iroh allowlist, enter the gateway NodeId, user and password.
- First start: right-click the app → Open (the app is not notarized yet).
